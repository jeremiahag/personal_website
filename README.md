# NORTH® — Visual Designer & AI Creative

A dark, editorial React + Vite portfolio starter for a desktop-first design portfolio, with responsive mobile styling.

## Run locally

Requirements: Node.js 18+.

1. Run `npm install`
2. Run `npm run dev`
3. Open the local URL printed by Vite.

## Before publishing

- Replace sample project images and the portrait with your own work.
- Update the placeholder email `hello@north.design` and portfolio identity `NORTH®`.
- Review the experience timeline and project descriptions.
- Hero video, fonts, and sample images load from external sources.

## Build

Run `npm run build` to create a production build.
